
# Laundry Services Hero Section

## Project Description
A responsive laundry service landing page created using HTML and CSS.

## Technologies
- HTML5
- CSS3
- Flexbox
- Media Queries

## How to Run
1. Open the project folder in VS Code.
2. Open index.html in your browser.
3. Ensure internet access for the laundry image.

## Features
- Navigation bar
- Hero heading and description
- Call-to-action button
- Laundry image
- Responsive layout
